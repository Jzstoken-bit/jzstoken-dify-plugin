# Privacy Policy

This plugin sends the configured JZSTOKEN API key, model ID, prompts,
conversation messages, tool definitions, and request parameters directly to
`https://jzstoken.com/api/v1`. Generated content, usage metadata, request IDs,
and errors are returned to Dify.

The plugin does not add analytics, telemetry, or persistent storage. Credentials
are stored by Dify using its normal plugin credential handling and are sent only
to JZSTOKEN as bearer authentication.

JZSTOKEN may process request metadata, IP addresses, usage data, and request
content to provide, secure, and bill the service. It forwards model requests to
the applicable upstream model provider. Those providers' terms and privacy
policies also govern their processing.

For JZSTOKEN's current privacy terms, use https://jzstoken.com. Privacy questions
can be submitted through https://jzstoken.com.
